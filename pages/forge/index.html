README.md

brine-gateway prices freight lanes for the Hollowmill network. A quote is always priced inside a rate window: windows are 900 seconds long and aligned to absolute boundaries, so two gateways pricing the same lane in the same window must agree on the price they charged.

Everything in src/tariff/ works in epoch seconds. Milliseconds appear only where a cache TTL is compared against Date.now(). Mixing the two is the most common defect in this area of the codebase.

Run the unit suite with npm test. The Anvil pipeline runs the same suite plus the staging replay set on every push.
