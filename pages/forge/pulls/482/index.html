tariff: cache lane quotes and align rate windows #482

Open t.ashgrove wants to merge 6 commits into trunk from tariff-cache-window
Conversation4 Commits6 Checks5 Files changed3
t.ashgrove opened this pull request on 14 July

Lane quotes are priced far more often than the tariff table changes, so the gateway was hitting the rate table once per request. This adds an in-memory cache keyed by lane, tariff class and rate window, and moves window maths into a module of its own so the pricing path and the reconciliation job agree on where a window starts and ends.

  • src/tariff/cache.js gains a real TTL, eviction and hit/miss counters.
  • src/tariff/window.js exports boundary helpers instead of one function.
  • src/tariff/quote.js reads through the cache and writes prices back to it.

Measured on the staging replay set: 41,900 quote requests dropped from 41,900 tariff table reads to 2,140. I have not touched the reconciliation job in this branch; that follows in a separate change once the helpers land.
