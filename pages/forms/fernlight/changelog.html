Changelog

Release notes for the Atlas 3 private beta.

3.0.0-rc4 — 2026-07-14

  • fixedCrash reporter no longer stalls the exit path when the network is unreachable; traces are spooled to disk and sent on next launch.
  • fixedInterchange export wrote an incomplete manifest when a project contained an empty layer.
  • tilesTile service retries now back off per host, cutting redundant requests on flaky links by about half.
  • changedReduced telemetry level now also omits per-tool timing samples.

3.0.0-rc3 — 2026-06-02

  • fixedGNSS import misread antenna heights recorded in feet; affected observations are flagged for review on upgrade.
  • tilesBase layers are pre-warmed for the visible extent after project open, removing the grey flash on first pan.
  • crashCrash reporting now includes the last twenty log lines, redacted of paths and coordinates.
  • fixedCode table edits no longer require a project reload to take effect.

3.0.0-rc2 — 2026-04-20

  • fixedWorkspace sync could duplicate a project if the first sync was interrupted; duplicates are merged on upgrade.
  • tilesNew tile cache eviction keeps the working set under the disk budget set in preferences.
  • changedThe doctor command now reports GPU driver age and warns below the supported baseline.

3.0.0-rc1 — 2026-03-09

  • newFirst release-candidate build issued to the beta cohort.
  • newInterchange export with checksummed manifest replaces the Atlas 2 bundle format.
  • newCrash reporting enabled by default, viewable locally before send.
  • tilesTile service moved to the workspace region selected at creation.
