Security

Reporting a vulnerability in Atlas 3 or in these pages.

How to report

Email security@fernlight.example with the build number (atlas --version), the steps to reproduce, and what you expected to happen. We acknowledge every report within two working days and tell you when a fix ships in a release candidate.

Scope

  • The Atlas 3 desktop client and the atlas command line.
  • Workspace keys, sync and the tile service.
  • This site and the waitlist form.

Please do not load-test the tile service or access another participant's workspace; clause 6 of the beta terms still applies while you investigate.

Workspace keys

If you think a workspace key has leaked, write to the beta address and we rotate it the same day. The old key stops working as soon as it is rotated.
