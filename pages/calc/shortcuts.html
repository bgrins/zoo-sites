Keyboard shortcuts

Shortcuts apply while the grid has focus. On the compact keyboard layout, use the Fn row equivalents.

Navigation

Arrow keysMove the selection one cell
Ctrl + GFocus the name box (Go to a cell reference)
Tab / Shift + TabMove right / left within a row

Editing

Start typingStart a new entry for the selected cell in the formula bar
Enter (formula bar)Commit the entry to the selected cell
EscCancel and restore the cell's saved entry
F2Focus the formula bar for the selected cell

Formulas

Ctrl + `Toggle Show formulas
Ctrl + Shift + AJump to the first formula-audit flag
F9Recalculate the sheet

Shortcuts cannot be remapped on workbooks opened over a shared link.
