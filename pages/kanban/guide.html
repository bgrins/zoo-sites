Using the triage board

Console guide for supervisors and controllers, issued with revision 7 of the triage rule. Read this before your first shift on the board.

Guide DC-02. Written by the dispatch systems group; queries to the duty controller on extension 2214.

Working the board

  1. Load the board and let it settle

    The lanes are drawn from the work order service, not from the page. Wait for the lane counts to appear before you touch a card; a lane that still reads zero has not been filled yet.

  2. Read each card before deciding

    A card carries the work order reference, the tag it was raised with, the berth or gate it belongs to, and when and by whom it was raised. The tag and the berth matter most: the tag says how urgently it needs a decision, the berth says who has to agree to it.

  3. Apply the triage rule, not your own order

    The triage rule is posted on the board itself and is reissued when it changes. Where a card looks like an exception, leave it where it is and raise it with the duty controller rather than inventing a placement.

  4. Move the card by whichever handle suits you

    Two handles do the same thing. Drag a card into the lane you want, or use the lane buttons at the foot of the card. Both record the same change, and neither is preferred. Within a lane, order carries no meaning.

  5. Save the board before you leave it

    Nothing is triaged until the board is saved. Save board sends every lane as a whole, so a save either takes the entire layout or is refused; there is no partial save. A refusal leaves the screen exactly as it was, so you can correct and save again.

  6. Check the revision line

    An accepted save prints a board revision. Quote that revision in the handover entry and in any query about the board. Saving again is not a mistake: each save gets its own revision and the latest one is the layout the handover report reads.

Discard changes

Discard changes throws away everything on screen and reloads the board from the service. It does not undo a save. If you have already saved and want the earlier layout back, put the cards where they belong and save again, then note both revisions in the handover entry so the incoming supervisor knows which one to read.

If the board will not load

The board is tied to the console session you signed in with. If the session lapses, the lanes stay on screen and a message appears above them; Discard changes reloads the board, and reloading the page starts a new console session. Nothing you had on screen at that point was saved, so expect to triage again.

What the incoming shift sees

The handover report is generated from the last saved layout. An unsaved board is invisible to it. That is the single most common query the duty controller takes at 16:00, and it is always the same fix: save the board.
