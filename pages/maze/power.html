Power and thermal

Bus, array and thermal readings for Kestrel 4, refreshed at each downlink. Values below are the sol 214 morning pass. Drive power draw is bounded by the interlock, so the traverse budget is set by array output and battery margin, not by drive count.

Electrical bus

BUS 28.3 V

BATT 87 PCT

ARRAY 412 W

LOAD 143 W

MARGIN 269 W

Battery state of charge must stay above 40 percent before the overnight heater load is committed. Below that floor the drive deck is inhibited for the rest of the sol.

Thermal zones

AVIONICS +18 C

BATT BAY +11 C

MOTOR 1 +26 C

MOTOR 2 +24 C

MAST HEAD -4 C

Motor windings are limited to +65 C. Repeated drives against the hazard interlock raise winding temperature without covering ground, which is one of the reasons refused headings should not be retried back to back.

Energy plan, sol 214

  • WAKE 07:40 LST heaters off
  • ARRAY peak expected 13:10 LST
  • DRIVE window 09:00-16:30 LST
  • COMM pass reserve 55 Wh held
  • SLEEP 18:05 LST heaters on

The drive window closes early if battery margin drops. Timing of downlinks is listed on the uplink windows sheet.
