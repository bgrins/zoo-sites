Help centre

Answers for the most common questions from workspace members. For anything else, contact support.

Renaming a file

Use the Rename action on the file's row. The list updates straight away and the change syncs to the workspace server; if the server declines the change (for example, the file is locked by a review hold), the row reverts and a notice explains why. Use Refresh on the notice to reload the list.

Seeing a file's details

Click a row to select it, then choose Get info in the toolbar for its size, owner, sharing and how long earlier versions are kept. Click a column heading to sort the list by it; click again to reverse the order.

Why are New folder and Upload greyed out?

Your access on this shared drive link is set by the workspace owner (see Members). Members with view or comment access can browse and search, but cannot add or remove items.

Where did a deleted file go?

Deleted items move to Trash and stay recoverable for 30 days. Only the member who deleted an item, or the workspace owner, can restore it.

Storage limits

The Team plan includes 100 GB of shared drive storage. See Manage storage for the current breakdown.
