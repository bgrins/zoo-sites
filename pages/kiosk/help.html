Using this kiosk

The display on this machine is not a touchscreen. Everything is driven from the metal keypad under the screen; the screen only shows what the keypad is doing.

Choosing an option

  • Every screen lists its options with a two-digit code. Typing a code on the keypad selects that option immediately — frequent travellers buy a ticket with three codes and never look at the list.
  • Or move the amber highlight with the up and down arrow keys, then press the round OK key to select the highlighted option. OK sends Enter.
  • The yellow C key clears anything typed into the entry field. C sends Escape.
  • Typing letters filters the list, so typing part of an option's name narrows it down before you arrow to it.

Paying

The kiosk quotes your exact fare on the review screen, including the time-of-travel adjustment in effect at that moment. Selecting Confirm purchase charges the card at the reader and shows a confirmation code. Quote that code for refunds or if an inspector asks about the ticket.

If the kiosk does not respond

Press C, then 92 to start over. If the screen stays frozen, use the help point on the wall by the gate line and quote kiosk K-4128-02.
