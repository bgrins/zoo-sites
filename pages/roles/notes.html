Desk notes

Working notes for consultants on the northern desk. Kept short and revised whenever the vacancy list changes shape.

Using the refine panel

Every value in the panel carries the number of vacancies it would leave, counted against the filters already applied in the other three groups but not against its own group. Read the number before ticking the box. A value showing nothing left is a value that empties the list.

Getting out of an empty list

An empty list is not a fault. Take one filter off the applied row above the results and the list comes straight back; clearing the whole panel is rarely necessary and loses the narrowing already done.

Secondary locations

Clients frequently say they will also consider a second town. That is a widening, not a replacement: it belongs alongside the base office rather than instead of it, and on several disciplines the second town carries no vacancies at all.

References

A vacancy reference is only shown on the vacancy record itself, never on the search list, so that a reference quoted to a client has always been read off the record it belongs to. Quote the reference in full when you confirm a shortlist.

Sharing a search

The address bar carries the applied filters, so a narrowed list can be pasted into a message and reopened exactly as it was. Reopening a pasted address applies the filters in one go rather than one tick at a time.
