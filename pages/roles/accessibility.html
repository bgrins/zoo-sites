Vacancy search · Accessibility

Accessibility

This statement covers the vacancy search and the pages around it. It was last reviewed in April 2026 and is revised whenever the search changes.

How the pages are built

The vacancy search is ordinary HTML with a stylesheet and a small amount of script. Text resizes with the browser's own controls up to twice its size without anything being clipped or overlapping, and the page reflows to a single column on a narrow screen. Nothing moves, flashes or plays on its own, and there is no audio anywhere on the site.

Using the refine panel without a mouse

Every filter is a real checkbox with a real label, so the tab key moves between them and the space bar ticks them. Ticking a box updates the vacancy list in place and adds the filter to the row above the results; each entry in that row is a button, reachable by tab, that takes its filter back off. The number beside a filter is read out as part of the label, so a screen reader user hears what a filter would leave before applying it. When a combination of filters leaves nothing, the list is replaced by a heading and an explanation rather than by an empty space.

Where we know we fall short

Three things are on the list to fix. The applied-filter row announces its own changes only on some screen reader and browser pairings, so a keyboard user may need to move back up to the row to confirm a filter has come off. The filter groups are marked up as fieldsets with legends, and a few older screen readers do not announce the legend, which makes two similarly named filters harder to tell apart. Pagination controls at the foot of a long result list are a long way from the results themselves for anyone using magnification at high levels.

Another way to do it

If any of that gets in the way, telephone the candidate line on 0808 157 0142 and a consultant will run the search with you and read out what is on the list. The desk will send a vacancy record as plain text, as large print, or on paper if you would rather have it that way, normally the same working day. Interviews arranged through the desk carry whatever adjustments you ask for, and the desk tells the client only what you agree it may tell them.

Telling us about a problem

Write to desk@alderpost.example with the address of the page and what happened, or telephone 0113 496 0180. Every report is answered within five working days, and anything that stops a candidate applying is treated as urgent rather than as a change request.
