Secrets / Release notes

Console release notes

What changed in the vault console, newest first. Vault storage and the console ship separately; storage changes appear here only where an operator would notice them.

Console 6.4

Rotation now asks for the whole current value as proof of possession before it will issue a replacement, and states so on the form. The masked form is rejected, which closes a route where an operator confirmed a rotation they could not actually have performed. Rotation receipts moved out of the flash message and onto the secret detail view, so the receipt survives a reload and can still be quoted in a change record an hour later.

Console 6.3

The self-service reveal control was removed. Every reveal now runs through a break-glass request countersigned by Security Engineering, as policy PD-04 has required since February. Copy is unaffected: a member holding the deploy role still places a value on their clipboard from the detail view, and the console still discards it once the write completes.

Console 6.2

Audit entries became append-only in the interface as well as in storage, so the log no longer offers a delete a custodian could not have carried out anyway. Clipboard outcomes are recorded alongside the read they belong to, which means a refused clipboard write is now distinguishable from a copy that succeeded. Environment badges on the secret list are set apart for production, after two incidents where a staging credential was rotated in mistake for its production counterpart.

Console 6.1

Namespaces gained the four-role model described on the roles page, replacing the single administrator flag. Existing administrators were migrated to custodian and everyone else to reader; teams then requested deploy where they needed it, which is why grant volumes spiked through March.

Console 6.0

The console was rebuilt around the sealed-value rule: no value is sent to the browser for display under any circumstance, and the detail view shows a prefix and last four characters only. Rotation, audit and policy each became a page of their own rather than tabs on one screen, and the rotation cadence recorded against a secret began driving the rotation-due list on the secrets page.

Coming

A namespace-level view of grants nearing expiry is in build for 6.5, along with a cadence report the desk can send to owners ahead of the quarterly reconciliation. Neither changes what an operator may see or copy. Requests for the roadmap go to the vault desk.
