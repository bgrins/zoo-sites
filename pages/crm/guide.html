Operator guide

How to work the v3 grids, what the workspace holds authoritative, and where a request goes when the console will not do it.

Reading a grid

Every grid page states its row count under the table, in the form rows shown over rows held. Where those two numbers agree you are looking at the whole set for the period; the console does not page a grid silently.

A grid never aggregates a column it does not own. Totals appear only in a table footer, and only where the source holds the figure.

Sort and column state

The v3 grid engine keeps column widths and sort order per operator, so a colleague opening the same page sees their own arrangement rather than yours. State is written when you leave the page.

On a shared workspace link there is nowhere to write it, so the arrangement lasts the session only.

What the snapshot means

Grids read the warehouse snapshot, rebuilt nightly at 02:00. An edit made during the day reaches the snapshot that night, which is why a stage change or a territory correction is not visible on a grid until the following morning.

The record itself is authoritative; the snapshot is what the console can see of it.

Shared workspace links

A shared link opens the workspace read-only. Saved views cannot be written, CSV export is unavailable, report delivery is disabled, and workflow tasks cannot be completed. Filter controls on a grid will accept input and then tell you the view is read-only rather than pretending to run.

There is no operator-side setting that lifts this. Link policy belongs to the workspace owner.

Getting figures out

Ask an owner to run the report you need from the catalogue under Reports. Where the report has been retired, the figures have to be compiled from the grids that still publish them, and the compiled working should be attached to whatever it was needed for.

Do not circulate a screenshot of a grid as a figure of record.

Period discipline

Quarter-end close is the 9th. An order recorded after close rolls into the next period and will not appear against the quarter you expected, so check the order date rather than the day you keyed it.

Fiscal 2026 runs January to December.
