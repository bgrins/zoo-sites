Maintenance windows

Windows run 22:00 to 02:00 on the last Saturday of the month and end with the nightly rebuild. Grids stay readable throughout; writes are held.

Next window 2026-08-29. Following window 2026-09-26.

Saved views after v3

Open

Views saved against the v2 grid engine did not survive the migration, because v3 stores a filter and a column arrangement as one object rather than two. Rebuilding them is tracked as a workspace task.

Saved views are read-only on shared workspace links, so a shared session cannot rebuild them.

Region rollup

Open

The rollup report was retired with the migration and no replacement date has been announced. Territory reassignments stay frozen while it is missing, so that the eventual report is not built over a moving assignment.

Owners may request an exception; analysts cannot.

Reporting a problem

Send the page name, the workspace id, the build shown in the path bar, and what you expected to see, to the support address in the footer. Include the row count line from under the grid where a grid is involved.

Notices are updated on working days by workspace operations.

Change log

3.14.2 corrected the path bar build label. 3.14.1 fixed column widths on narrow displays. 3.14.0 moved Orders and Customers onto the v3 grid engine and introduced per-operator sort and column state.

Engine changes are listed on the dashboard as they ship.
