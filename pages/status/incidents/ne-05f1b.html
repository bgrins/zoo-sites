Incident history / NE-05F1B

API gateway elevated error rate

NE-05F1B 2026-06-19 02:12 to 02:58 Resolved

Affected component: API gateway.

Updates

  1. Resolved2026-06-19 02:58

    The affected cache node has been reprovisioned and error rates on the API gateway have been normal for a full window.

  2. Identified2026-06-19 02:31

    A cache node restarted with stale route tables and is answering some requests with 5xx errors. The node has been drained while it is reprovisioned.

  3. Investigating2026-06-19 02:12

    We are seeing an elevated rate of 5xx responses from the API gateway, affecting roughly 2 percent of requests.

Postmortem

A routine restart of one gateway cache node restored its route tables from a snapshot taken before the previous day's change, instead of fetching current tables. About 2 percent of API requests were routed by that node for 46 minutes and failed.

Health checks passed throughout because the node answered them from the same stale tables. The node was found by correlating error rates per node.

A restarted node now refuses traffic until its route tables match the current version, and health checks compare the version they serve against the control plane.
