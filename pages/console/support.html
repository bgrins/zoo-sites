Contact

Email support@cindergrid.example.net with the run id and, for failed runs, the support bundle id from the end of the run log (for run 4192 that is sb-4192). Bundles are sealed at the end of every run and kept for fourteen days, so quote them early.

For a production outage outside support hours, the same address pages the on-call engineer; put OUTAGE in the subject line. Billing questions go to accounts@cindergrid.example.net.
